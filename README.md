# Software Security Reviewer

เครื่องมือตรวจสอบความเสี่ยงซอฟต์แวร์และแพ็กเกจเบื้องต้นแบบ **Portable Single-File Web Application (`index.html` ไฟล์เดียว)** ออกแบบมาเพื่อช่วยประเมินความปลอดภัย ช่องโหว่ CVE สถานะการสนับสนุน และความเสี่ยงด้านข้อมูลรั่วไหลก่อนอนุญาตให้ติดตั้งใช้งาน โดยสามารถเปิดใช้งานผ่านเว็บเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริมและไม่ต้องใช้สิทธิ์ Administrator

---

## ความสามารถหลัก (Key Features)

* **Universal Input & Dependency Parser:** รองรับการกรอกชื่อซอฟต์แวร์พร้อมเลขเวอร์ชันหลากหลายรูปแบบ ทั้งการพิมพ์ติดกัน ชื่อไฟล์ตัวติดตั้ง (`.exe`, `.msi`, `.dmg`, `.whl`) เลขเวอร์ชันผสมตัวอักษร ไปจนถึงรูปแบบแพ็กเกจจาก `requirements.txt` (เช่น `package==1.0.0`, `>=`, `~=`)
* **Multi-Source Version & Lifecycle Check:** ตรวจสอบเวอร์ชันเสถียรล่าสุดและสถานะหมดอายุการสนับสนุน (End-of-Life / Deprecated / Yanked) แบบ Real-time จากฐานข้อมูลสาธารณะหลายแหล่งพร้อมกัน (PyPI, Homebrew Formulae/Casks, endoflife.date, Wikidata และ GitHub Releases)
* **Version-Applicable CVE & Exploit Filtering:** คัดกรองเฉพาะช่องโหว่ CVE และ Security Advisories ที่กระทบเวอร์ชันเป้าหมายจริง รองรับการเทียบแพตช์แยกหลายสายเวอร์ชัน (Multi-branch fixes) และการตรวจสอบช่องโหว่ที่ถูกใช้โจมตีจริง (CISA KEV)
* **Context-Aware DLP, Privacy & Agentic Risk Analysis:** วิเคราะห์ความเสี่ยงเชิงพฤติกรรมตามหน้าที่จริงของซอฟต์แวร์ (เช่น ความเสี่ยงการโอนย้ายข้อมูลออกนอกองค์กร, การบันทึกรหัสผ่านแบบไม่เข้ารหัส, ความเสี่ยง Indirect Prompt Injection ในกลุ่ม Autonomous AI Agents / MCP Clients และความเสี่ยงด้าน Supply-chain) พร้อมสรุปเงื่อนไขการตั้งค่าความปลอดภัย (Hardening)
* **Live Vendor Domain & Local SHA-256 Verification:**
  * ดึงสถานะโดเมนผู้ผลิตสดผ่าน DNS-over-HTTPS เพื่อตรวจสอบความมีอยู่จริงของโดเมน (`A`/`CNAME`, การแจ้งเตือน `NXDOMAIN`) และมาตรฐานป้องกันการสวมรอย (`SPF`, `DMARC`, `DNSSEC`)
  * รองรับการคำนวณค่า Hash (`SHA-256`) ของไฟล์ตัวติดตั้งภายในเบราว์เซอร์ของผู้ใช้ 100% โดยไม่มีการอัปโหลดไฟล์ออกนอกเครื่อง

## วิธีใช้งาน (How to Use)

1. **ใช้งานออนไลน์ผ่าน GitHub Pages:**
   เปิดใช้งานได้โดยตรงผ่านลิงก์:
   `https://dizconnectz.github.io/Software-Security-Checker/`
2. **ใช้งานแบบ Offline / Portable บนเครื่อง:**
   ดาวน์โหลดเฉพาะไฟล์ `index.html` เก็บไว้ในเครื่อง แล้วดับเบิลคลิกเพื่อเปิดด้วยเบราว์เซอร์มาตรฐาน (Microsoft Edge, Google Chrome, Firefox หรือ Safari) ได้ทันที

## ขอบเขตการใช้งานและข้อจำกัดความรับผิดชอบ (Disclaimer)

เครื่องมือนี้จัดทำขึ้นเพื่อช่วยรวบรวมข้อมูลความปลอดภัยจากฐานข้อมูลสาธารณะสำหรับประกอบการพิจารณาเบื้องต้น (Decision-Support Tool) เท่านั้น ผลการประเมินไม่ได้รับรองความปลอดภัยสมบูรณ์ 100% โดยเฉพาะซอฟต์แวร์เฉพาะทางของเอกชนที่ไม่ได้เผยแพร่รหัส CPE หรือประวัติเวอร์ชันสู่สาธารณะ ผู้ตรวจสอบควรพิจารณาควบคู่กับนโยบายความปลอดภัยขององค์กรและเอกสารทางการจากผู้ผลิตเสมอ
